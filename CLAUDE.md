# BURAQ logistics — сайт отгрузок и планов

Фирменный стиль — обязателен для всего видимого (цвета, шрифт, логотип, кнопки, иконки):

@buraq-brand/BRAND.md

- Цвета сайта — токены в `css/design-system.css` (`--buraq-*`, `--color-*`); новых цветов в разметку не добавлять.
- Логотип — только файлы из `buraq-brand/logo/` (на синем — `buraq-logo-white.svg`, на светлом — `buraq-logo.svg`).
- Шрифт — Inter из `fonts/` (веб-замена Neue Montreal), заголовки капсом обычной толщины.
- Интерфейс для сотрудников — на русском; тексты для клиентов — на узбекском латиницей (см. BRAND.md).
